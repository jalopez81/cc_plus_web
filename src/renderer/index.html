Traducción
  • Auto: usa DeepL si tienes key; si no, Google, MyMemory y Apertium, el primero que responda.
  • DeepL: la mejor calidad. Necesita una key; el plan gratis trae 1.000.000 de caracteres en total, una sola vez (pasos abajo).
  • Google: gratis y sin key. Puede limitarse si se usa mucho.
  • MyMemory: gratis, unos 5.000 caracteres al día; 50.000 si pones tu email.
  • Apertium: gratis, pero de menor calidad. Último recurso.
  • Off: solo transcripción, sin traducir.
API key gratis de DeepL
  1. Abre y elige el plan gratis DeepL API Developer.
  2. Crea tu cuenta. DeepL puede pedir una tarjeta para verificar tu identidad; el plan gratis no cobra.
  3. En tu cuenta, abre la pestaña API Keys y copia la clave.
  4. Elige DeepL en la lista, pega la clave en su campo y pulsa Done.

El plan gratis incluye 1.000.000 de caracteres en total: no se renueva cada mes. Cuando se acaba, usa Auto (MyMemory con tu email y Google) o pasa a un plan de pago de DeepL.

Paraphrase
API key gratis de Gemini
  1. Abre e inicia sesión con tu cuenta de Google.
  2. Acepta los términos si te los pide y pulsa Create API key.
  3. Copia la clave (empieza por AIza).
  4. Pégala en este campo y pulsa Done.

Es gratis y no pide tarjeta. El plan gratis tiene un límite de solicitudes por minuto y por día, de sobra para usar Paraphrase durante las llamadas.
